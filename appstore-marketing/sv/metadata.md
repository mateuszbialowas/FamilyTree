## Description (max 4000)

```
Bygg ett släktträd över din familj — snabbt, utan konto och utan moln. Allt stannar på din telefon.

Lägg till föräldrar, barn, syskon och äktenskap. Bläddra i en komplett familjekrönika med födelse- och dödsdatum samt egna anteckningar.

Börja med dig själv och låt släktträdet växa generation för generation.

VAD APPEN KAN
• Visuellt släktträd med panorering och zoom
• Lägg till personer med förnamn, efternamn, kön, födelse- och dödsdatum
• Relationer: förälder ↔ barn, äktenskap (med vigsel- och skilsmässodatum), syskon
• Syskon kopplas automatiskt via gemensamma föräldrar
• Komplett personlista med sökning på namn
• Byt trädets rot — se din släkt genom varje anas ögon
• Anteckningar på varje person

INTEGRITET FÖRST
• Fungerar helt offline
• Inget konto, ingen inloggning, inget moln
• Din data lämnar aldrig enheten
• Ingen reklam, ingen spårning

FÖR VEM
• Människor som bygger ett släktträd för eget bruk
• Hobbysläktforskare som dokumenterar familjehistoria
• Alla som vill lämna sina barn en ordnad familjekrönika

Ladda ner appen och starta ditt släktträd idag.
```
