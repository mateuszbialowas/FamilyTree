## Description (max 4000)

```
Bygg et slektstre over familien din — raskt, uten konto og uten sky. Alt forblir på telefonen din.

Legg til foreldre, barn, søsken og ekteskap. Bla gjennom en komplett familiekrønike med fødsels- og dødsdatoer samt egne notater.

Start med deg selv og la slektstreet vokse generasjon for generasjon.

HVA APPEN KAN
• Visuelt slektstre med panorering og zoom
• Legg til personer med fornavn, etternavn, kjønn, fødsels- og dødsdato
• Relasjoner: forelder ↔ barn, ekteskap (med vielses- og skilsmissedatoer), søsken
• Søsken kobles automatisk gjennom felles foreldre
• Komplett personliste med søk på navn
• Bytt treets rot — se slekten din gjennom enhver forfars øyne
• Notater på hver person

PERSONVERN FØRST
• Fungerer helt offline
• Ingen konto, ingen innlogging, ingen sky
• Dataene dine forlater aldri enheten
• Ingen reklame, ingen sporing

FOR HVEM
• Folk som bygger et slektstre til eget bruk
• Hobby-slektsforskere som dokumenterer familiehistorie
• Alle som vil etterlate barna sine en ryddig familiekrønike

Last ned appen og start slektstreet ditt i dag.
```
