# Datenschutzerklärung

**Zuletzt aktualisiert:** 2. März 2026

## Überblick

Stammbaum ist eine mobile Anwendung zum Erstellen und Verwalten von Stammbäumen. Ihre Privatsphäre ist uns wichtig — die App ist so konzipiert, dass alle Ihre Daten auf Ihrem Gerät bleiben.

## Datenerhebung

Stammbaum erfasst, überträgt oder speichert **keine** persönlichen Daten auf externen Servern. Alle Familiendaten (Namen, Daten, Beziehungen) werden ausschließlich auf Ihrem Gerät über lokalen Speicher (AsyncStorage) gespeichert.

## Datenspeicherung

- Alle Daten werden lokal auf Ihrem Gerät gespeichert
- Keine Daten werden an Server oder Cloud-Dienste gesendet
- Keine Analyse- oder Tracking-Tools werden verwendet
- Keine Cookies werden verwendet

## Datenexport

Die App ermöglicht den Export Ihrer Familiendaten als JSON-Datei. Diese Datei wird lokal erstellt und nur über von Ihnen ausdrücklich gewählte Methoden geteilt (z. B. AirDrop, E-Mail). Der Entwickler hat keinen Zugriff auf exportierte Dateien.

## Drittanbieterdienste

Stammbaum integriert keine Drittanbieterdienste, die Benutzerdaten erfassen.

## Datenschutz für Kinder

Die App erfasst wissentlich keine Informationen von Kindern. Alle Daten verbleiben auf dem Gerät und werden niemals übertragen.

## Änderungen dieser Richtlinie

Wir können diese Datenschutzerklärung von Zeit zu Zeit aktualisieren. Änderungen werden auf dieser Seite mit aktualisiertem Revisionsdatum veröffentlicht.
