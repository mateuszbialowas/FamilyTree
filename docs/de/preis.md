# Preis

FamilyTree ist ein **einmaliger Kauf**. Einmal kaufen, für immer nutzen — kein Abo, keine In-App-Käufe, keine Werbung, kein Konto.

Deine Daten bleiben auf deinem iPhone. Keine Cloud, keine Server, kein Tracking.

## Preis in deiner Region

Der App Store zeigt dir den Preis automatisch in deiner Landeswährung. Richtwerte:

| Region | Preis |
| --- | --- |
| **Deutschland, Österreich, Eurozone** | **6,99 €** |
| Schweiz | CHF 5,00 |
| Vereinigtes Königreich | £5,99 |
| Vereinigte Staaten | $5,99 USD |
| Polen | 24,99 PLN |
| Schweden | 79 SEK |
| Norwegen | 79 NOK |
| Dänemark | 49 DKK |

Preise werden von Apple festgelegt und können leicht mit dem Wechselkurs variieren. Der exakte, aktuelle Preis für dein Land wird dir im App Store vor dem Kauf angezeigt.

## Was du bekommst

- Unbegrenzten Stammbaum auf deinem iPhone
- Eltern, Kinder, Ehepartner und Geschwister hinzufügen — erweiterte Verbindungen (Großeltern, Cousins) werden automatisch erkannt
- Wunderschöne, handgezeichnete Visualisierung
- Export und Weitergabe an die Familie; Import von Bäumen
- 100 % offline. Nach der Installation kein Internet erforderlich.
- Kein Konto. Keine Cloud. Keine Analytics.
