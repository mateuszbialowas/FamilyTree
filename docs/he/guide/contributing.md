# תרומה לפרויקט

תודה על העניין שלכם בתרומה ל-אילן יוחסין!

## תחילת העבודה

1. בצעו fork של המאגר
2. שכפלו את הfork שלכם: `git clone https://github.com/YOUR_USERNAME/FamilyTree.git`
3. התקינו תלויות: `npm install`
4. צרו ענף: `git checkout -b feature/your-feature`

## תהליך פיתוח

1. בצעו את השינויים
2. בדקו על סימולטורי iOS ו-Android
3. הריצו בדיקות E2E: `npm run test:e2e`
4. בצעו commit עם הודעה תיאורית
5. בצעו push ופתחו Pull Request

## סגנון קוד

- TypeScript בכל מקום — הימנעו מטיפוסי `any`
- עקבו אחר תבניות קיימות לרכיבים ומסכים
- השתמשו בנושא המרכזי (`src/theme/`) לצבעים, גופנים ומרווחים
- טקסט UI חייב להיות בפולנית (שפת האפליקציה)

## הוספת מסך חדש

1. צרו את המסך ב-`src/screens/`
2. הוסיפו אותו למקבץ הניווט המתאים ב-`src/navigation/`
3. הוסיפו בדיקת Maestro E2E ב-`.maestro/`

## דיווח על בעיות

פתחו issue ב-GitHub עם:

- תיאור ברור של הבעיה
- שלבים לשחזור
- התנהגות צפויה לעומת בפועל
- מידע על מכשיר/סימולטור

## רישיון

על ידי תרומה, אתם מסכימים שתרומותיכם יורשו תחת רישיון MIT.
